# 车醒瞳安公网部署说明

## 推荐方式

使用 Render 或 Railway 部署，获得一个带 HTTPS 的公网网址。HTTPS 很重要，因为其他电脑访问时，浏览器通常只允许在 HTTPS 或 localhost 页面调用摄像头。

## Render 部署步骤

1. 在 GitHub 新建一个私有或公开仓库。
2. 将 `car_ai_agent` 文件夹中的项目文件上传到仓库。
3. 注册或登录 Render，选择 **New Web Service**。
4. 连接 GitHub 仓库，根目录选择 `car_ai_agent`。
5. Build Command 填写：

   ```text
   pip install -r requirements.txt
   ```

6. Start Command 填写：

   ```text
   gunicorn --bind 0.0.0.0:$PORT --workers 1 --threads 4 --timeout 300 web_app:app
   ```

7. 创建服务，等待构建完成。Render 会生成类似下面的 HTTPS 地址：

   ```text
   https://car-ai-agent-xxxx.onrender.com
   ```

## 比赛演示注意事项

- 公网服务使用云端算力处理摄像头帧，实时画面会发送到部署服务器；这与当前本地隐私模式不同，必须在页面隐私说明和答辩中明确告知。
- 免费实例可能休眠，第一次打开需要等待几十秒；正式比赛建议使用不会休眠的实例。
- 当前系统没有登录和访问控制，不建议长期公开运行。比赛前应增加访问密码或限制评委使用时间。
- 上传视频和报告会占用服务器磁盘；正式部署前应增加自动清理策略，不保存不必要的原始视频。
- 系统仍是比赛原型，不作为真实道路驾驶安全系统或医疗判断。

## 本地部署检查

部署前在项目根目录运行：

```powershell
python -m py_compile web_app.py src\review_agent.py src\evaluate_cases.py
```

如果服务平台提供环境变量，设置：

```text
CAR_AI_AGENT_HOST=0.0.0.0
```
