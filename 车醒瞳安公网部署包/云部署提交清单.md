# 云部署提交清单

上传到 GitHub 时保留：

- `web_app.py`
- `src/`
- `config/`
- `requirements.txt`
- `Procfile`
- `render.yaml`
- `README.md`
- `公网部署说明.md`

不要上传：

- 原始驾驶员视频；
- 含人脸的标注视频；
- `data/uploads/` 中的临时上传文件；
- `reports/web/` 中的临时结果；
- 不完整的 `cloudflared.exe`。

## 需要你提供的唯一外部权限

要生成真正的公网网址，必须由你完成一次 GitHub 和 Render 登录授权。登录完成后，我可以继续帮你检查部署日志、修改启动配置和验证生成的网址。
