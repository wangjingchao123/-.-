1. 项目背景 随着机动车保有量增长和驾驶任务复杂度提升，疲劳驾驶、分心驾驶和低头操作已成为道路交通安全中的重要风险因素。在驾校训练、汽车专业实训和企业驾驶安全培训中，教练通常依靠人工观察判断学员是否疲劳或分心，存在观察不连续、标准不统一、训练后难以复盘等问题。  现有车载驾驶员监控系统多面向量产车辆，通常依赖红外摄像头、专用芯片、车载网络和车规级认证，成本较高，难以直接用于普通驾校和学校实训场景。  因此，本项目设计“车醒瞳安”驾驶员状态分析与智能复盘 Agent，在不接入车辆硬件的前提下，利用普通摄像头和本地 AI 分析技术，对驾驶员疲劳、分心、姿态异常和监测可信度进行识别，为驾驶训练提供可解释的风险提醒和复盘建议。
